# Capstone Demo

The graded submission includes a narrated **4:47 MP4 demo video** named `Arne_B_Ramos_Pillar_5_Capstone_Project_Demo.mp4`.

This GitHub repository tracks the exact narration in [`Demo_Video_Transcript.txt`](Demo_Video_Transcript.txt) and the reproducible Streamlit research prototype in [`../app/streamlit_app.py`](../app/streamlit_app.py). The full MP4 is delivered with the LMS submission package rather than duplicated in Git history.

The demo covers:

1. Cybersecurity problem and success metrics
2. UNSW-NB15 data and target-leakage safeguards
3. EDA and feature engineering
4. Logistic Regression, Random Forest, and XGBoost comparison
5. Final test metrics and threshold trade-offs
6. SHAP global and local explanations
7. Operational subgroup/error audit
8. Streamlit research prototype
9. Generative AI disclosure and verified code examples
10. Limitations and deployment recommendation

The video is a presentation artifact; the reproducible evidence remains in the notebooks, source modules, reports, figures, and tests in this repository.
